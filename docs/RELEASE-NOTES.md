# Castlevania: Harmony of Despair на Nintendo Switch — реліз-нотатка (чернетка, 2026-10-31)

Статична рекомпіляція Xbox 360 (XBLA) версії гри для Switch (homebrew NRO, libnx + deko3d).
Дані гри **не входять** у збірку: потрібна власна копія XBLA-пакета.

## Збірка

| Файл | Версія | SHA-1 |
|---|---|---|
| `cvhd.nro` | `0.249.f6f3674` | `10986139e44f7358ed43188fb5e143c3c84cbe2f` (84 391 777 байт, з іконкою гри) |

Поруч з NRO на картці (`sdmc:/switch/cvhd/`): маркер `deko3d` (порожній файл), каталог `shaders/` (26 `*.dksh`),
каталог `game/` (`default.xex` + `data/` з пакета, без `default.xexp`). Іконка NRO — іконка тайтлу з пакета гри.

## Що працює

- Запуск як title takeover (hbmenu: утримати R на будь-якій грі), 1785/768 МГц.
- Одиночна гра: меню 60 fps, геймплей 40–45 fps нерівно у режимі 60 або рівні 30 у режимі 30 (консоль
  0.249: GPU 12–13 мс на кадр, CPU ~50 мс на кадр на три ядра, тому 60 fps недосяжні). Усі шість персонажів
  перекомпільовано; в Eden перевірено лише Сому.
- **Меню налаштувань у грі** (кнопка «мінус»): FRAME RATE 60 / 30 / 30 SKIP (30 = показ кожні 33 мс і
  vblank-переривання гри 30 Гц, щоб крок часу гри був рівний; файл `sdmc:/switch/cvhd/vblank60` лишає
  vblank 60 Гц, як у 0.249), RUMBLE,
  VOLUME, FPS COUNTER, BUTTON ICONS (SWITCH / XBOX, після перезапуску), EXIT GAME. Зберігається в
  `sdmc:/switch/cvhd/settings.txt`; старі файли-маркери `fps`, `mute`, `norumble` читаються один раз, якщо
  `settings.txt` ще нема.
- Кнопки за позицією: Switch B (знизу) = Xbox A, A = B, Y = X, X = Y; «+» = START, «мінус» = меню налаштувань
  (на 360 це BACK: колесо швидких реплік LIVE, офлайн непотрібне). Підказки на екрані (A OK / B Back тощо)
  перемальовані під літери Switch: гліфи міняються місцями в пам'яті при читанні файлів гри, дані на картці
  не змінюються.
- Вібрація (обидва Joy-Con / Pro Controller / портативний режим), звук через audout.

## Що не працює / не зроблено

- **Мультиплеєр: лише Xbox LIVE.** У 360-версії немає локального кооперативу (`ArcadeInfo.xml`: MaxPlayers=1
  офлайн; пункт меню вимагає входу в LIVE; слоти гравців — члени LIVE-сесії через XNet/UDP). Локальний режим
  потребував би заглушки XSession з фальшивими учасниками — не реалізовано.
- Title update (TU) не застосовано (рекомпільовано базовий XEX); DLC не підключено.
- Підказки кнопок: перевірено головне меню і паузу (`ranktex_0.dds`); аркуші екрана спорядження та
  `ui_obj01` (A/B розрізані краєм сторінки) — частково; екран Help & Options показує картинку Xbox-геймпада.
- Завантаження стадії з SD повільне (кілька секунд, libnx fs IPC на файл).

## Затримка вводу

Драйвер пада читає стан HID при кожному опитуванні гри (раз на кадр гри: 60/с на консолі при 60 fps, у Eden
27–28/с), без власної черги. Ланцюжок: HID (~5 мс у портативному, ~15 мс по Bluetooth) → опитування в кадрі
гри → логіка → рендер → present на наступному vblank (режим 30 fps додає до 16,7 мс). Вимірювання на
консолі: рядок `[nx] pad: N polls/s` у `cvhd_log.txt`.
